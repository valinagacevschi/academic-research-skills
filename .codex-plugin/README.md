# Codex plugin adapter

This adapter packages the repository's shared ARS skills for Codex. The canonical skill content remains in the top-level skill directories; the root `skills/` links point to those directories so the adapter does not fork their instructions.

For setup and runtime limitations, see [Codex CLI setup](../docs/SETUP.md#codex-cli) and [control availability](../docs/CONTROL_AVAILABILITY.md).
